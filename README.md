iNaturalist is a nature observation platform and citizen science network that connects people to nature through biodiversity observation and identification. The iNaturalist API provides programmatic access to over 200 million wildlife observations, species identifications, taxon data, and biodiversity records contributed by citizen scientists worldwide. The API supports reading and writing observations, taxa lookups, identifications, places, projects, and user data across v0, v1, and v2 endpoints.

**Areas:** Biodiversity · Nature · Citizen Science · Wildlife · Observations · Taxa · Ecology

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for iNaturalist: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
