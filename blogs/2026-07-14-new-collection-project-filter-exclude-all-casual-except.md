Key Takeaways It's now possible to include observations marked captive/cultivated in a collection project while still keeping out other casual grade observations We've had requests for this functionality over the years, and it's also been a long-time option for traditional projects. Just a quick update, we added a new Quality Grade filter to collection project requirements. If you select "Casual" as an option, you'll now see an "Exclude All Casual Except Captive" option appear below it.
